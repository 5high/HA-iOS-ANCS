SETUP STEPS

安装后的连接步骤

按刷写、设置 AP、保存 Wi-Fi/MQTT、在设置门户内注册 iPhone、Home Assistant Discovery、验证通知的顺序进行。

!
HACS 边界 HACS 只安装 Home Assistant 伴侣集成。ESP32 固件的刷写与更新请使用本浏览器安装器或源码构建流程。

01 / FLASH

刷写固件

在桌面版 Chrome 或 Edge 中用数据线连接 ESP32，选择板子系列后点击安装按钮。仅当需要同时清除 Wi-Fi、MQTT 与 BLE 配对时才选择 full erase。

02 / SETUP AP

连接设置 AP

刷写完成后连接 IOSMSG-XXXXXX Wi-Fi，密码为 iosmsg-xxxxxx。XXXXXX 是设备基础 Wi-Fi MAC 地址的最后 6 位十六进制：SSID 用大写，密码用小写。它不是型号编号。

03 / PROVISION

保存 Wi-Fi 与 MQTT

在浏览器打开 http://192.168.4.1，保存 Wi-Fi 与 MQTT broker 信息。同页的 注册 iPhone 设备 按钮可在不离开页面的情况下打开注册窗口。

04 / HOME ASSISTANT

确认 MQTT Discovery

ESP32 连上 broker 后，MQTT Discovery 会在 Home Assistant 中创建设备和 iPhone 注册开始 按钮。HACS 伴侣集成可通过 HACS My 链接添加，但它不会刷写固件。

05 / PAIR

iPhone 配对

通过设置门户的 注册 iPhone 设备、Home Assistant 的 iPhone 注册开始，或长按 BOOT 3 秒，打开 120 秒注册窗口。在 iOS 蓝牙中输入固定 PIN 654321 并允许通知共享。

06 / VERIFY

验证通知

确认 Home Assistant 中“最近通知”和“App 名称”已更新。优先使用 iPhone 提供的 ANCS Display Name，首次查询后使用连接会话缓存。即使查询失败通知也不会丢失，会回退到静态映射与原始 App ID。回退对照表见 App ID 参考文档。

症状 检查项
看不到 USB 串口 检查桌面版 Chrome/Edge、HTTPS Pages 地址和数据 USB 线。
看不到设置 AP 刷写完成后等待设备重启；必要时长按 BOOT 3 秒打开恢复窗口。
门户打不开 确认已连接 IOSMSG-XXXXXX，再打开 http://192.168.4.1。
Home Assistant 中没有设备 检查 MQTT broker 连接、Discovery 是否开启、retained config 是否已发布。
找不到 iPhone 检查 120 秒注册窗口是否开启，以及 iOS 蓝牙权限。
通知为空 检查是否允许通知共享、iOS 通知设置以及 MQTT payload。
